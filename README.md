# SvelteKit Electron

A ready-to-use template to use SvelteKit in Electron.

## Getting Started

### Project Structure

The UI is a basic [SvelteKit](https://svelte.dev/docs/kit/introduction) skeleton which is compiled to a static site using [prerendering](https://svelte.dev/docs/kit/adapter-static). The desktop app is built using [electron-builder](https://www.electron.build/).

### Run it locally

- Clone the project.

```bash
    git clone https://github.com/fiorelorenzo/sveltekit-electron.git
    cd sveltekit-electron
```

- Install the dependencies.

```bash
    npm install
```

- Start the app in dev mode

```bash
    npm run dev
```

### Build the desktop application

- Build the Svelte application.

```bash
    npm run build
```
